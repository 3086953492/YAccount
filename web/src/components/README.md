# 组件库组织结构

本项目的组件按照功能和用途进行了分类组织，便于维护和查找。

## 📁 文件夹结构

```
components/
├── form/           # 表单相关组件
├── ui/             # 通用UI组件
├── layout/         # 布局相关组件
└── README.md       # 本文件
```

## 🎯 分类说明

### 📝 form/ - 表单组件
包含所有与表单相关的组件，如输入框、按钮、卡片等。

**组件列表:**
- `FormCard.vue` - 表单卡片容器
- `FormInput.vue` - 表单输入框
- `FormButton.vue` - 表单按钮
- `FormFooter.vue` - 表单页脚
- `FormValidator.vue` - 表单验证器

**详细文档:** [form/README.md](./form/README.md)

### 🎨 ui/ - 通用UI组件
包含可复用的基础UI组件，如加载器、消息提示等。

**组件列表:**
- `LoadingSpinner.vue` - 加载动画
- `ErrorMessage.vue` - 错误消息提示
- `SuccessMessage.vue` - 成功消息提示

### 🏗️ layout/ - 布局组件
包含页面布局相关的组件，如导航栏、侧边栏等。

**组件列表:**
- `Navigation.vue` - 导航栏组件

## 🔧 使用建议

1. **导入路径**: 使用相对路径导入组件，如 `@/components/form/FormInput.vue`
2. **组件分类**: 新增组件时，请根据功能放入相应的子文件夹
3. **命名规范**: 组件文件名使用PascalCase，如 `FormInput.vue`
4. **依赖关系**: 注意组件间的依赖关系，避免循环依赖

## 📚 扩展指南

### 添加新组件
1. 确定组件功能类别
2. 在对应子文件夹中创建组件
3. 更新相关文档
4. 测试组件功能

### 组件命名规范
- 表单组件: `Form` + 功能名
- UI组件: 功能描述 + 类型
- 布局组件: 布局位置 + 功能名

## 🚀 最佳实践

1. **单一职责**: 每个组件只负责一个功能
2. **可复用性**: 设计组件时考虑通用性
3. **类型安全**: 使用TypeScript定义Props和Events
4. **样式隔离**: 使用scoped样式避免样式冲突
5. **文档完整**: 为每个组件提供使用说明和示例
